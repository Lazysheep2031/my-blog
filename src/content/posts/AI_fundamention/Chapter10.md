## 概述

这一讲讨论的是 **智能体（AI Agent）**。它回答的核心问题是：

> **如何让 AI 从“被动回答问题”，进化到能够自主感知环境、规划步骤、调用工具、主动完成一个完整任务？**

这一讲的逻辑主线：

- 先理解 **智能体的定义**：它不是“更高级的聊天机器人”，而是能感知、决策、执行的系统；
- 再看两条技术路线：**基于强化学习的智能体** 和 **基于大语言模型的智能体**；
- 接着拆解 LLM 智能体的 **核心组件**（规划、记忆、工具使用、行动、交互）和 **核心特征**；
- 然后理解 **单智能体与多智能体、三种人机协作模式、通用人工智能 AGI**；
- 最后通过 **里程碑案例（深蓝、AlphaGo、AlphaZero、HuggingGPT）和 Coze 实训** 建立完整画面感。

> **智能体 = 大脑（LLM 或策略）+ 记忆 + 工具 + 规划 + 行动——它代表 AI 从“会说”走向“会做”。**

## 什么是智能体

**智能体（AI Agent）** 是能够自主感知环境、作出决策并执行特定任务的人工智能系统。它代表 AI 技术发展的关键前沿方向。

智能体有两种形态：

- **物理形态（Robot）**：特斯拉全自动驾驶汽车、扫地机器人、宇树科技人形机器人等；
- **软件形态**：Siri、小爱同学等语音助手，以及大语言模型驱动的任务助手（能自动订机票、写报告、调用工具完成多步任务）。

> **智能体的关键跃迁是从“被动回答问题”到“主动执行任务”。**

---

## 基于强化学习的智能体

强化学习旨在让智能体（机器人、游戏角色、下棋程序等）通过与环境的互动来学习，以最大化收益或最小化损失。

它与其他机器学习方法的本质区别在于：**强化学习通过智能体与环境的互动来学习，而监督 / 无监督学习通过训练数据来学习。**

强化学习有六大核心要素：

| 要素 | 含义 |
|---|---|
| 智能体（Agent） | 强化学习的主体，根据策略做出判断并执行动作 |
| 环境（Environment） | 智能体以外的一切；能被动作影响，并向智能体反馈状态和奖励 |
| 状态（State） | 智能体对环境的一种理解和编码，包含影响决策的信息 |
| 动作（Action） | 智能体对环境产生影响的方式 |
| 策略（Policy） | 在给定状态下选择动作的规则 |
| 奖励（Reward） | 智能体采取一系列动作后从环境获得的收益 |

一个直观例子（超级马里奥）：

> **游戏画面是环境，玩家操控的“超级马里奥”是智能体，通过手柄操作（动作）来获取最大分数（奖励）——这就是强化学习的完整闭环。**

深度强化学习进一步用深度网络解决高维复杂决策问题。

## 基于大语言模型的智能体

大语言模型能接受输入、分析推理、输出文字 / 代码 / 媒体，但它无法像人一样规划思考、使用工具与物理世界互动、拥有持久记忆。

一个精妙的类比：

> **如果人类只有大脑，没有四肢、没有工具，是没办法与世界互动的。如果我们给大模型配上“四肢”（工具）、“记忆”和“规划思考能力”呢？**

$$
\text{人类} = \text{LLM（接受输入、思考、输出）} + \text{记忆} + \text{工具} + \text{规划}
$$

**基于大语言模型的智能体** 就是一种以 LLM 为核心，具备规划思考能力、记忆能力、使用工具能力，能自主完成给定任务的计算机程序。

在这种智能体中，**LLM 充当“大脑”的角色**，同时还有三个关键部分：

### 规划（Planning）

规划可以理解为“观察和思考”，包含两个方面：

- **子任务分解**：把大型任务分解为更小、更可控的子任务。例如“帮我安排下周出差”会被拆成“查日历找空闲日 → 订机票 → 订酒店 → 加日程 → 通知同事”。思维链（CoT）是这里的常用技术——要求 LLM“think step by step”，它就会把问题分解成多步逐一解决，使输出更准确。
- **反思和完善（Reflection）**：在执行过程中对已完成的子任务进行反思，从错误中吸取教训、完善后续步骤，并判断任务是否完成、是否终止。例如订机票失败后，智能体能分析是“航班满了”还是“信用卡过期”，并调整方案。

### 记忆（Memory）

仿照人类的记忆机制，智能体实现两种记忆：

- **短期记忆**：当前任务执行过程中产生的信息（如某个工具或子任务的执行结果），相当于上下文窗口内的对话历史；在任务过程中产生和暂存，任务完结后被清空；
- **长期记忆**：长时间保留的信息，一般指外部知识库（通过 RAG 实现），通常用向量数据库来存储和检索。

### 工具使用（Tool use）

为智能体配备工具 API，如计算器、搜索工具、代码执行器、数据库查询工具等。有了工具，智能体才能与物理世界交互、解决实际问题。

> **易错点：智能体想获取“实时天气”这类信息，靠的是“工具使用”组件（调用搜索 / 天气 API），而不是靠 LLM 本身的知识——这是考试的典型场景题。**

## 智能体的核心组件

结合前面的“大脑 + 三个关键部分”，智能体的核心组件通常归纳为五个（有的教材扩展为“感知、决策、行动、记忆、规划、反思”六大组件，本质一致）。

| 组件 | 功能 |
|---|---|
| 规划组件（Planning） | 通过事前规划和事后反思，分解复杂任务、制定执行策略，在经验中逐步优化 |
| 记忆组件（Memory） | 用短期记忆理解当前上下文，用长期记忆存储海量信息与专业知识，支持个性化 |
| 工具组件（Tools） | 调用外部资源和 API 获取额外信息与分析能力，弥补知识局限、增强与环境交互 |
| 行动组件（Action） | 将规划转化为实际执行，通过“感知—决策—行动”闭环与环境持续互动 |
| 交互 / 协作组件（Interaction） | 通过分工合作、信息共享、协同决策实现多智能体协同，可能涌现集体智慧 |

> **一句话记忆：规划（怎么做）、记忆（记住什么）、工具（用什么做）、行动（去做）、交互（一起做）。**

## 智能体的核心特征

智能体的主要特征可归纳为六点，每一点都能对应一个典型场景：

| 特征 | 典型场景 |
|---|---|
| 自主性 | 无人驾驶汽车感知环境、自主决策并执行，无需人类干预 |
| 完备能力 | 扫地机器人具备“感知—分析—执行”的完整信息处理链 |
| 生成能力 | ChatGPT 理解输入并生成自然对话，实现问答、建议、创意写作 |
| 多功能性 | Amazon Alexa 能播放音乐、控制智能家居、检索信息等多种任务 |
| 持续学习 | 工业机器人监测操作错误、调整参数、持续优化装配行为 |
| 人机协作 | 达芬奇手术机器人结合人类操控与机器精度，精确执行微创手术 |

## 单智能体与多智能体

- **单智能体模式**：一个智能体独立完成从感知到行动的完整闭环，适合简单任务。
- **多智能体协作（Multi-Agent）**：多个智能体分工合作、通过信息共享完成复杂任务。例如一个团队里有“项目经理 Agent”“程序员 Agent”“测试员 Agent”各司其职。

多智能体能提高效率和鲁棒性，但也带来新的工程挑战：如何协调？如何处理冲突？一个子智能体出错时如何防止错误传播？

> **易错点：多智能体不是“智能体数量多了自然变强”，协调成本可能反而拖累系统。**

## 人机协作的三种模式

课程特别提出三种人机协作模式（源自浙大研究），难度逐级递增，AI 的自主度也逐级提升：

- **Embedding 型（小帮手）**：AI 嵌在人类工作流里做局部辅助，人主导；
- **Copilot 型（副驾驶）**：人机并行协同、各有分工，如 GitHub Copilot 辅助写代码；
- **Agent 型（代理人）**：AI 自主代理执行任务，人只设定目标，如“帮我搞定出差”。

> **从 Embedding 到 Agent，AI 的自主度指数级递增，工程难度也指数级递增。**

## 通用人工智能 AGI

**通用人工智能（Artificial General Intelligence, AGI）** 指能理解和解决任何人类水平任务的 AI。

与狭义人工智能（Narrow AI）不同，AGI 具备四大特征：广泛知识覆盖、跨领域学习迁移、高级推理、自我认知。

当前大语言模型在某些维度已接近 AGI 特征（能写代码、讲笑话、做推理），但在任务场景感知、持续学习、深层认知能力上，与真正的 AGI 仍有本质差距。

> **AGI 的到来时间在业界极大争议：OpenAI、Anthropic 高管常给“5 到 10 年内”的预测，而 Yann LeCun 等学者认为现有 LLM 路线根本走不到 AGI。目前 AGI 尚未公认到来，任何宣称“已实现 AGI”的产品都需警惕。**

## 里程碑案例

智能体的发展有一条清晰的棋类 / 游戏对抗主线：

- **深蓝（Deep Blue，1997）**：击败国际象棋冠军卡斯帕罗夫，靠的是搜索算法和专家系统，为后续自我学习的智能体奠定基础；
- **AlphaGo（2016）**：通过自我对弈和深度学习实现决策优化，击败李世石，融合了联结主义（策略网络、价值网络）与行为主义（强化学习）；
- **AlphaZero**：DeepMind 开发的自我博弈智能体，不依赖人类棋谱，从零通过自我对弈掌握围棋、国际象棋等深层规律，展现强大的通用性；
- **AlphaStar / Atari**：把智能体推广到实时策略游戏和视频游戏，超越传统棋类。

**HuggingGPT** 则代表另一条路线——大小模型协同：

> **通用大模型有基础知识但面对专用任务力不从心；而 Hugging Face 上托管着 30 多万个轻量、专用的小模型。HuggingGPT 用大模型（ChatGPT）作“调度中枢”，通过任务规划 → 模型选择 → 任务执行 → 响应生成，调度上万个 AI 模型解决跨模态复杂任务。**

小模型在这里充当大模型连接物理世界的接口，感知多模态信息，增强大模型对物理世界的深层理解。

## 智能体实训：Coze

**扣子（Coze）** 是新一代 AI 应用开发平台，无论是否有编程基础，都能快速搭建基于大模型的智能体并发布。

在 Coze 中，智能体的核心组件有对应的功能区：

| 组件 | 对应功能 |
|---|---|
| 行动组件 | 提示词与人设、模型设置 |
| 工具组件 | 插件 |
| 规划组件 | 工作流、图像流、触发器 |
| 记忆组件 | 知识库、变量、数据库、长期记忆 |
| 交互组件 | 多智能体模式 |

以“建筑设计趋势分析 Bot”为例，其流程是：

1. 确定与建筑设计相关的关键词组合；
2. 调用搜索引擎，根据关键词搜索网页；
3. 根据搜索结果合成趋势分析报告；
4. 根据报告进一步优化关键词，生成产品概念图。

这个案例把“规划（工作流串联）+ 工具（必应搜索、图片生成插件）+ 记忆（Bot 变量存储报告和网址）+ 行动（提示词与人设）”完整地体现了出来。
